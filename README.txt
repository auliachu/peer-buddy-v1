PEER BUDDY WEBSITE — MULTI-PAGE PROTOTYPE

Files:
- index.html             Home
- profile.html           Profile / About / History / Vision & Mission / Team
- publications.html      Publications + live client-side search/filter
- news.html              News & Activities
- organization.html      Organization Structure
- styles.css             Shared styles
- script.js              Shared JavaScript

How to preview:
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. Navigation works locally without a server.

Search behavior:
- Search on publications.html is client-side JavaScript.
- It searches only publication cards already present in the HTML.
- For future database/CMS search, a backend or API can be connected.
